a program that writes one one-line joke about office life to `/output/entry.txt`.

The joke:

> I set my calendar to 'do not disturb', so my boss booked a meeting titled 'Quick question about your do not disturb'.

Why this line: the setup is a calendar block every office worker has set,
the turn makes the block itself the reason for a meeting — the exact thing
the block was meant to prevent — and the punchline lands last on the most
recognised words in office life, "quick question". It states no complaint
plainly; the joke is the reversal.

## Run it

Requires Node 22 or later (the entrypoint is TypeScript run as-is):

```sh
node main.ts
cat /output/entry.txt
```
